# Sign Korean — 간판으로 고르는 서울 여행 계획

> 거리의 한국어 간판을 읽으며, 그 간판이 걸린 곳으로 서울 여행 일정을 짜는 모바일 앱의 기획과 인터랙티브 프로토타입

생성형 AI와 서비스개발 (3학년 2학기) · 중간고사 대체 과제

---

## 어떤 앱인가

한글을 대략 읽을 수 있는 방한 외국인을 위한 앱입니다. 거리의 간판 단어를 익히고, 그 간판을 볼 수 있는 장소를 골라 여행 일정에 넣습니다.

**1순위는 여행 계획, 2순위는 간판 학습**입니다. 학습은 계획으로 들어오는 입구 역할을 합니다.

```
[국밥] 카드  →  아래로 스와이프  →  국밥 간판을 볼 수 있는 시장 4곳 (사진·리뷰·위치)
                                  →  마음에 드는 곳을 여행 일정에 추가
```

### 학습 카드 조작 (Tinder식)

| 동작 | 의미 |
|---|---|
| **오른쪽 스와이프** | 알아요 · I know |
| **왼쪽 스와이프** | 몰라요 · Don't know → 3장 뒤에 다시 나옴 |
| **아래 스와이프** | 그 간판을 볼 수 있는 장소 목록 |
| **카드 탭** | 뒤집어서 로마자·발음·뜻 보기 |
| 오른쪽 위 북마크 | 카드 저장 |

화면 아래 원형 버튼(`✕ · ↓ · ✓`)과 키보드(`← → ↓ Enter`)로도 똑같이 조작할 수 있습니다. 처음 들어가면 방향 안내 시연이 한 번 나옵니다.

### 주요 기능

- **간판 학습**: 장소 유형 간판 35장과 거리 기초 표지판 100장(화장실·미세요/당기세요·영업시간·환승 등 6분류). 모든 카드에 로마자 표기와 🔊 발음 듣기가 있습니다.
- **장소 탐색**: 서울 8개 지역, 장소 49곳. 장소 카드에서 사진·리뷰·주소를 봅니다.
- **여행 계획**: 날짜별 일정, 장소 순서 변경, 도보 경로 개략도
- **수익 모델**: 무료 + US$0.99 1회 결제. 학습과 장소 탐색은 무료이고, 여행 계획·경로·무제한 북마크(무료는 5개)가 유료입니다. 프로토타입의 결제는 시뮬레이션이라 실제로 과금되지 않습니다.

## 실행 방법

| 방법 | 설명 |
|---|---|
| **가장 쉬움** | [`Sign_Korean_인터랙티브_디자인.html`](Sign_Korean_인터랙티브_디자인.html)을 내려받아 더블클릭합니다. 설치·서버·빌드가 필요 없습니다. |
| 소스로 실행 | [`prototype/index.html`](prototype/index.html)을 브라우저로 엽니다. |

- 학습 기록·저장한 카드·여행 일정은 **이 브라우저에만** 저장됩니다. 서버로 보내지 않습니다.
- 장소 사진(TourAPI)은 인터넷에서 불러옵니다. 오프라인이면 사진 자리만 비고, 나머지 기능은 그대로 동작합니다.
- 발음은 브라우저 내장 음성합성을 씁니다. 그래서 목소리는 브라우저·OS마다 다릅니다.

## 데이터와 사진 출처

| 대상 | 출처 | 라이선스 |
|---|---|---|
| 장소 사진 25곳 | 한국관광공사 TourAPI (`KorService2`) | 공공누리 제1유형 14 · 제3유형 11 |
| 장소 사진 3곳 (경복궁·명동성당·DDP) | Wikimedia Commons (앱에 내장) | CC0 · CC BY 4.0 ([credits.json](prototype/assets/credits.json)) |
| 장소 사진 17곳 (역·거리·쇼핑몰 등) | Wikimedia Commons 16 · Flickr 1 ([commons_photos.js](prototype/commons_photos.js)) | CC0 7 · CC BY 10 |
| 간판·표지판 이미지 | 앱이 SVG로 직접 그림 | 해당 없음 |
| 장소 이름·주소·좌표 | 공개된 사실 정보. 좌표는 Wikidata(CC0)·TourAPI(공공누리 제1유형) | 거리·골목 8곳은 근사치(`.work/coordinates_report.txt`) |
| 리뷰 | **샘플 데이터** | 실제 리뷰 아님 |

- 사진마다 화면에 출처를 표시합니다. CC BY 사진은 저작자와 라이선스도 함께 표시합니다.
- 을지로 인쇄골목·연남동 카페거리 2곳은 그 장소를 보여 주는 쓸 수 있는 사진이 없어 비워 두었습니다. 근처 다른 장소의 사진으로 대신하지 않습니다.
- 공공누리 제3유형은 **변경 금지**라서 자르지 않고 원본 비율로 보여줍니다.
- 간판 사진은 쓰지 않습니다. 직접 촬영할 수 없고, 리뷰 사진은 저작권이 작성자에게 있어 쓸 수 없습니다. 자세한 근거는 PRD §11.2에 있습니다.
- `Example`이 붙은 장소 4곳은 개별 상점을 대신하는 예시이며, 실제 상호가 아닙니다.

### 장소 사진 다시 받기

1. [공공데이터포털](https://www.data.go.kr/data/15101578/openapi.do)에서 「한국관광공사_국문 관광정보 서비스_GW」를 활용신청합니다.
2. 저장소 루트에 `.env` 파일을 만들고 아래 한 줄을 넣습니다. 이 파일은 `.gitignore`로 제외되어 커밋되지 않습니다.

   ```
   TOUR_API_KEY=<일반 인증키(Decoding)>
   ```

3. 아래 명령을 실행합니다.

```bash
py -X utf8 .work/fetch_tourapi.py
```

```bash
py -X utf8 .work/package_html.py
```

검색 결과를 그대로 쓰지 않고, 아래 다섯 조건을 모두 통과한 사진만 채택합니다. 장소별 판정 결과는 [`.work/tourapi_report.txt`](.work/tourapi_report.txt)에 남습니다.
1. 장소 이름으로 시작할 것
2. "~점"으로 끝나는 지점이 아닐 것
3. 관광지·문화시설·쇼핑 유형일 것
4. 등록 좌표에서 1.5km 이내일 것
5. 공공누리 제1·3유형일 것

인증키는 앱 코드에 들어가지 않습니다.

Commons 보충 사진은 [`.work/fetch_commons.py`](.work/fetch_commons.py)의 `PICKS`에 **직접 보고 확인한 파일만** 적어 둡니다. 실행하면 라이선스와 저작자를 Commons에서 다시 읽어 `prototype/commons_photos.js`를 만들고, 허용 범위(CC0·Public domain·CC BY)를 벗어나면 멈춥니다.

```bash
py -X utf8 .work/fetch_commons.py
```
